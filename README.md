# FM1 - Oktowave Firmware

> **Two editions.** `main` = **OKTOWAVE**: Felucca with all its engines plus WAVELET. `wavelet-groovebox` = **OKTOGROOVE**: Felucca's groovebox with WAVELET as its sound engine (WAVELET + DRUM only offered, the other engines hidden). Same sources, one define (`OKTOWAVE_GROOVEBOX`) in `src/felucca.c`; see the manual, section 12.

[![License: GPL-3.0-only](https://img.shields.io/badge/license-GPL--3.0--only-blue.svg)](LICENSE)

**OKTOWAVE** is an alternative firmware for the M-VAVE FM-1 pocket synthesizer: Hügelton Instruments'
[Felucca](https://github.com/hugelton/Felucca) 1.6.1 (four tracks, 13 synthesis engines, sequencer, arpeggiator,
effects, USB audio and MIDI) plus one more engine, **WAVELET**: engines A (subtractive) and B (additive) of the
[Wavelet Synthesizer](https://github.com/PierreArnaudGUYOT/Free-Wavelet-Synthesizer-VST) by Pierre Arnaud GUYOT
(OktoPierre), rewritten in fixed point for the FM-1's processor, with both engines of the Wavelet Synthesizer (A and B) and 108 of its presets.

One cycle of a source wave is split by a discrete wavelet transform (Haar, Daubechies 2 to 20, a symlet, a coiflet)
into nine bands of atoms, the smallest atoms can be dropped (SPARSITY), and the bands are played through a scale
filter (low-, high- or band-pass in bands, with slope and resonance) and a window that lets the dry cycle through.

- **Manual**: [docs/manual.html](docs/manual.html)
- **Install, try in the browser, manual online**: the GitHub Pages site of this repository (built by the workflow)
- **Releases**: the `.fwsc` package
- **Build**: [BUILDING.md](BUILDING.md) (Felucca's). The JieLi toolchain is Linux only, so the build and the tests run
  on GitHub Actions: [.github/workflows/build.yml](.github/workflows/build.yml)

> **Version 0.1 has not been run on an FM-1 yet.** Built with the official toolchain on GitHub Actions and tested on
> computers only: the engine's standalone test (every wave and wavelet, the presets, a sample-for-sample check of the render,
> the cross-fade, the scale of engine B, a floating-point reference of the tables) and the browser build; Felucca's own host suite
> runs in the workflow too, with golden renders for the 108 WAVELET presets (none of Felucca's own renders changed).
> Installing a custom firmware is at your own risk: back up first and keep the way back to the official firmware.

## What is where

| Path | What |
| --- | --- |
| `firmware/src/eng_wavelet.c` | the WAVELET engine: table build (DWT, sparsity, layers) and voices |
| `firmware/src/wavelet_tick.c` | per-block scheduler of the builds and cross-fades (called from `fx.c`) |
| `firmware/src/wavelet_tables.h`, `wavelet_presets.h` | generated by `tools/gen_wavelet_tables.py` and `tools/gen_wavelet_presets.js` |
| `tests/wavelet_test.c`, `tools/wavelet_ref.js` | standalone engine test and the floating-point reference |
| `tests/budget_test.c` | the shared voice budget: a WAVELET voice counts as two of the eight |
| `tools/export_wavelet_presets.js`, `tools/gen_wavelet_presets.js` | the presets out of the Wavelet Synthesizer's sources, then into `wavelet_presets.h` |
| everything else | Felucca 1.6.1; `firmware/engines/` is the Felucca-Engines submodule (MIT) |

Changes to Felucca's own files are small: engine table, order and power-on parts (`engines.c`, `core.h`, `main.c`), the tick
in `fx.c`, the voice budget's weights (`voice.c`: a WAVELET voice counts two), engine names, costs, MIDI CC and categories (`params.c`, `fx.c`, `midi_control.c`, `category.c`), the favourites
and MIDI-learn guards (`favorites.c`, `midi_learn.c`), the version string, package names, installer and emulator pages,
`tests/target_budget.py`. Felucca's own power-on sounds stay what projects of older formats and the host tests see.

## Engine test (any C compiler and Node.js)

```sh
mkdir -p build/host
python3 tools/gen_tables.py build/host/felucca_tables.h
cc -O2 -std=gnu99 -I build/host -o build/host/wavelet_test tests/wavelet_test.c -lm
build/host/wavelet_test build/host
node tools/wavelet_ref.js build/host
```

## How it was made

The WAVELET engine, its tools, tests, manual and the changes to Felucca were written with the help of an AI assistant
(Claude, Anthropic) under the direction of Pierre Arnaud GUYOT, and reviewed by a second, independent AI agent (its
findings and the fixes are in the git history). Felucca's own README has an AI disclaimer of its own; see Felucca's repository.
